4. Speicherung in Ihrem Browser

Damit zwei Funktionen der Seite wie gewünscht arbeiten, legt die Website kleine Einträge im Speicher Ihres Browsers ab:

  • rm-lang (Local Storage): merkt sich die Sprache, die Sie auf der Seite für Techniker gewählt haben. Der Eintrag bleibt bestehen, bis Sie ihn in Ihrem Browser löschen.
  • rm-booker-closed (Session Storage): merkt sich, dass Sie das Fenster zur Terminanfrage geschlossen haben. Der Eintrag wird gelöscht, wenn Sie den Tab schließen.

Diese Einträge werden nicht an uns oder Dritte übertragen. Sie sind unbedingt erforderlich, um die von Ihnen gewünschte Funktion bereitzustellen (§ 25 Abs. 2 Nr. 2 TDDDG). Sie können sie jederzeit über die Einstellungen Ihres Browsers löschen.
